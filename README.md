bandcamp-sync
=========================

Aim of this is to download new purchases from Bandcamp.

And then import them to Apple Music.

Let's do this in Swift.

1. Start with a CLI tool that can list recent purchases from Bandcamp.
2. then let it enumerate the content of Music
3. then let it find purchases not in Music
4. and load them to Music
5. put a GUI on it for normal people
